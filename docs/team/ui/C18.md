### C18 · Tab bar                                                     size: M
Place in the tree: journal › JR-1 › tab bar (also PC-1, GL-1, YO-1, YO-2, ON-13)

Why: four places, always in reach, with the current one shown by weight rather than colour. The page above softens into the bar instead of stopping at a hard plate.

- Code anchors: `RSymbol` (template glyphs); `RHaptic.tab`; `RMotion.snappy`, `RMotion.gentle`

Spec:
- **Structure:** the app's tab container is a `TabView(selection:)` with the system bar hidden (`.toolbar(.hidden, for: .tabBar)`), so each tab keeps its own `NavigationStack` and state. `RTabBar` is overlaid at the bottom. (The container is the integrator's app shell; this byte delivers `RTabBar` and a gallery container that hosts four sample tabs.)
- **Bar:** height `size.tabBar` 49 plus the home-indicator inset; no plate, no line. The page under it is opaque canvas, and the `.tabEdge` blur sits above it.
- **Items:**
  - four equal slots of 72, centred; on SE a slot shrinks but never below 64 (computed from the container width, never the device model)
  - each item is a 22pt glyph over a Geist 11 lowercase label, 2pt apart, the pair centred by mass
  - selected: emphasis glyph (2.2 outline) `text.primary`, label Geist 500 `text.primary`
  - rest: 1.75 glyph `icon.muted`, label Geist 400 `text.label`
- **Mini-player:** floats 12pt above the bar (C22). The bar never contains it. The content inset is the bar plus the mini-player when something plays.

State table:

| State | Look | Motion | Haptic |
|---|---|---|---|
| rest / selected | the weights above | none | none |
| pressed | glyph and label at `opacity.pressed` 0.7 | 80 in / 240 out | none |
| change | old item to rest weight, new to emphasis; the page swaps | glyph `scale.press` → 1 on `snappy`; label weight cross-fades 140ms | `tab` on selection |
| re-tap the selected tab | — | its page scrolls to top on `RMotion.gentle` | none |
| dark | dark tokens; inactive glyph contrast 3.3 : 1 | — | — |

Interaction table:

| Touch | Press | Haptic | Motion | Outcome | Reduce Motion |
|---|---|---|---|---|---|
| a different tab | dim 0.7 | `tab` | settle on `snappy`, 140ms label fade | selection changes; the tab's stack is preserved | no scale; instant weight swap |
| the selected tab | dim 0.7 | none | the page scrolls to top on `gentle` | top of the page (pops to root if pushed: second tap) | jumps to top |
| long press (AX sizes) | — | none | large-content viewer | shows glyph and label | same |

Accessibility:
- the bar has the `.isTabBar` container trait; each item is a button with `.isSelected` when selected
- the label is "journal" and so on; VoiceOver reads "journal, tab, 1 of 4, selected" (verify the exact phrase in the UI test and record it)
- at AX3 and above, labels hide and glyphs stay 22; `.accessibilityShowsLargeContentViewer` shows glyph and label
- Increase Contrast: inactive glyphs become `text.secondary`
- Reduce Transparency: the edge goes opaque (UI0.1)
- no badges ever

Steps: item → bar → gallery container with four sample tabs → edge → snapshots → recordings.

Acceptance:
- Matches `B3R-0` and `1FKD-0` in light and dark; selection is never shown by colour alone.
- Switching tabs keeps each tab's scroll position.
- Re-tapping scrolls to top.
- SE slots are ≥ 64.

Tests:

Proof in the PR: standard proof, plus the tab-change and re-tap recordings, and SE.

Watch out:
- `.symbolEffect` doesn't apply: the glyphs are template images. Use the scale settle.
- Missing emphasis glyphs for podcasts, goals and you: request them before starting. Never fake emphasis with `fontWeight` on an image.
- Hiding the system tab bar on iOS 26 also hides the Liquid Glass bar. Check that `TabView`'s safe-area inset doesn't leave a gap: the inset comes from `RTabBar`'s `safeAreaInset(edge: .bottom)`.
