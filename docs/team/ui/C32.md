### C32 · Evidence row                                                size: S
Place in the tree: journal › JR-4 › what i took › sources (also podcasts › PC-3, goals › GL-2, you › YO-3/YO-4)
Repo · branch: NPRdoinglaundry · ui/C32-evidence-row
Needs: T01        Unblocks: UI1.2, P15, P17, P20, P21

Why: whenever Retro says something about you, you can see exactly where it came from: one row per source, in your own words.

Inputs:
- Reference: design-reference §C32 (no spec file; sources: handoff part 41, build note c-7iso8b, decisions 02 and 04)
- Paper:
  - part 41 "why this is here" `G1E-0` (approved)
  - instances: PC-3 `c:evidence-row/rest` `1FYW-0`, GL-2 `1G52-0`, YO-4 `1GDI-0`
  - decision 02 `BQC-0` (inked icons), decision 04 `BZV-0`
- Code anchors: `RIconWell` (S01), `RSettingsRow` (its row shape and press), `RHairline`

Spec:
- **Anatomy** (a grouped list using the settings row's shape):
  - a 32 kind well: `radius.default` 10, `surface.wash`, a 20pt inked glyph `icon.default` (`journal`, `calendar`, `health`…)
  - a date and kind label: Geist 12 `text.label`
  - one line of your words: `type.text.md`, `text.primary`, `.lineLimit(1)`, `.truncationMode(.tail)`, filling the width between the well and the chevron
  - a `chevron-right` glyph `icon.muted`
  - rows separated by a 1pt `border.subtle` line, not a 0.5 hairline
  - row min height and paddings from `get_computed_styles` on `1FYW-0`
- **Variant hook:** `leading: .kind(RSymbol) | .number(Int)`. The numbered mono well is built with YO-2 (P19); this byte ships the `.kind` case only and leaves the enum open.

State table:

| State | Look | Motion | Haptic |
|---|---|---|---|
| rest | as above | — | — |
| pressed | row wash `surface.washPressed` | 80 in / 240 out | none |
| loading | three skeleton rows (C39.1) | shimmer | — |
| offline | cached rows, no change | — | — |
| on a tinted parent | `surface.lifted` instead of wash | — | — |
| dark | dark tokens | — | — |

Interaction table:

| Touch | Press | Haptic | Motion | Outcome | Reduce Motion |
|---|---|---|---|---|---|
| row | wash | none | 80/240 | opens the source (the parent decides: JR-4 for an entry) | same |

Accessibility:
- one element: "<date>, <kind>, <full excerpt>, button" (the full text in the label even though the row truncates)
- AX3: the excerpt can grow to 2 lines (the only exception to one line; never clipped mid-glyph); the well stays 32
- Increase Contrast: the separator becomes `border.strong`

Acceptance:
- Matches `1FYW-0` value for value.
- Never wraps at default sizes.
- A long excerpt truncates with an ellipsis.

Tests:
- (snapshot) rest, pressed, long excerpt, light, dark and ax3
- (UI) VoiceOver reads the full excerpt of a truncated row

Proof in the PR: standard proof.

Watch out:
- The separator is 1pt `border.subtle`. The merged `RHairline` is 0.5, so don't reuse it here.
- Use the row press from `RSettingsRow` so every list presses the same way.
