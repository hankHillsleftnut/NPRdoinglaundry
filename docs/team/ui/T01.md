### T01 · Snapshot harness for every component state                 size: M
Place in the tree: product › foundations › testing › component snapshots (layer 6)
Repo · branch: NPRdoinglaundry · ui/T01-snapshot-harness
Needs: PL0.1 (the test plan runs in CI), PL0.4 (`swift-snapshot-testing` pinned in `Package.resolved`), and an integrator PR that adds the `RetrospectSnapshotTests` unit-test target (hosted by the app) to the `Snapshots` test plan
Unblocks: every component and page byte (each adds its snapshots here)

Why: today nothing stops a merged component from quietly changing. With this, every approved state is pinned in light, dark and large text, and any drift fails CI with an image diff.

Inputs:
- Testing: [testing.md](../testing.md) §1 layer 6, §4 (recording configuration: iPhone 17 Pro, iOS 26.0)
- Library: Point-Free `swift-snapshot-testing` (the pinned version), `assertSnapshot(of:as:)` with `.image(precision:perceptualPrecision:layout:traits:)`
- Code anchors:
  - `DesignSystemV2/Components/RButton.swift`, `RSegmented.swift`, `RSettingsRow.swift` (merged components to cover first)
  - `DesignSystemV2/Parts/RParts1.swift`, `RParts2.swift`
  - `RFoundationGallery.swift` (the existing state lists)
- Fonts: the app registers Exposure and Geist at launch; the test host must do the same before the first render

Spec:
- **Helpers** (`RetrospectSnapshotTests/Support/RSnapshot.swift`):
  - `assertComponent(_ view:, named:, width: CGFloat = 342, file:, testName:, line:)` renders the view at `sizeThatFits` within a 342-wide proposal on `background.canvas`, three times:
    - `light`
    - `dark`
    - `ax3`: `.accessibilityExtraLarge`, light
  - `assertPage(_ view:, named:, device: .iPhone17Pro | .iPhoneSE)` renders full screen with the safe areas of the device, three times (light, dark, ax3), plus once on SE light for pages.
  - Precision `0.995`, `perceptualPrecision: 0.98` (absorbs antialiasing; catches a 1pt shift and any colour token change). Any change to these numbers is the integrator's call.
- **Determinism:**
  - an `RSnapshotEnvironment` sets a fixed date (2026-10-21 08:00 in `America/Los_Angeles`), `locale en_US`, Reduce Motion **off** (states are static views, not mid-animation), and `UIView.setAnimationsEnabled(false)`
  - shimmer and life animations get a `.rFrozen` environment flag (`RMotion` modifiers read it) so a skeleton renders at a fixed phase. This is a request to the integrator (`RMotionModifiers.swift` is shared): the flag only, no behaviour change in the app.
- **Fonts:** `RSnapshotFonts.register()` runs once in the test bundle's `setUp` with the app's font registration function (no copied font files).
- **Naming:** `__Snapshots__/<TestFile>/<testName>.<light|dark|ax3|se>.png`. Test names read as sentences, for example `test_button_lit_pressed()`.
- **Coverage in this PR:** every state of the merged components (`RButton` lit/raised/secondary/text × rest, pressed, disabled, pending; `RSegmented` 2/3 × each selected; `RSettingsRow` every kind), and the parts (`RIconWell`, `RStatusDot` each status, `RProgressHairline` 0/0.5/1, `RSpinner` frozen, `RSectionLabel`). Components still in review add their own snapshots in their PRs, or in a follow-up the integrator assigns if they merge first.
- **CI:** the `ios` job runs `xcodebuild test -testPlan Snapshots` on the integrator's simulator configuration. Failures upload the `Failures/` diff images as an artifact (the integrator wires the upload step).

Steps:
1. Support helpers and fonts.
2. Freeze flag request.
3. Merged components' snapshots, recorded on iPhone 17 Pro iOS 26.0.
4. Verify that a deliberate one-token change fails, then revert it.
5. Record the PR.

Acceptance:
- `xcodebuild test -testPlan Snapshots` passes locally and in CI on a clean checkout.
- Changing one colour token, or moving a component by 1pt, fails with a diff image (shown in the PR, then reverted).
- AX3 renders larger text (visible in the ax3 images), proving Dynamic Type flows through.
- Exposure and Geist render (not SF fallback) in every image.
- No real clock, locale or randomness reaches a snapshot.

Tests (layer 6):
- a lit button at rest matches its approved image in light, dark and ax3
- a pressed lit button matches its approved image
- a disabled button fades as one layer (fill and shadow together)
- every segmented selection matches its image
- every settings row kind matches its image
- a frozen spinner renders the same image twice
- a deliberately wrong token fails the snapshot (run once for the PR proof, not committed)

Proof in the PR:
- the list of recorded images
- one failing-diff screenshot from step 4
- CI run link
- the timing of the snapshot job

Watch out:
- Snapshots recorded on any other simulator configuration will fail CI. Record only on iPhone 17 Pro, iOS 26.0, on your assigned simulator with the same runtime.
- `sizeThatFits` on a view with `maxWidth: .infinity` renders 342 wide by design. Don't fight it.
- Don't snapshot animations mid-flight. Motion is proved by recordings (layer 10).
- PNGs are committed. Keep component images tight (no device frame) so the repo stays small.
