# Retrospect tokens

The foundation of the design system. **Tokens only; no components yet.**

- [`tokens.json`](./tokens.json) is the **one source of truth** (W3C design-tokens format). Swift and Figma will be generated from it, never edited by hand.
- [`TOKENS.md`](./TOKENS.md) is the readable table, regenerated by the validator.
- [`validate.mjs`](./validate.mjs): run `node design-system/tokens/validate.mjs`. It fails if a reference is broken, a token has no purpose, a colour has no dark value, a name describes a look, or a token has no source. It prints the live counts (total · semantic · marked `to set`) to the terminal; they are deliberately not written into `TOKENS.md`, so that file only changes when a token does and no longer conflicts on every merge.

## How to read a token

```
color.action…   category . role . variant . state
```

| Tier | Example | Rule |
|---|---|---|
| **Palette** | `palette.sky.400` | raw values; only tokens reference them, never screens |
| **Semantic** | `color.text.label` | named for what it's **for**; used everywhere |
| **Composite** | `type.label.button`, `elevation.primaryAction` | a full style for one role |

- The light value is `$value`; the dark value is `$extensions.retrospect.dark`. Screens never mention a mode.
- Every token has a purpose line (`$description`) and a **source**: `paywall` (measured from the current paywall screen), `lime` (Lime's structure or value), or `to set` (a default for you to refine).
